TRUSTDESI Dairy Daily Checklist - PWA files

Upload these files to the ROOT of your public GitHub repository:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

Then enable GitHub Pages:
Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.

Open the published HTTPS URL in Safari on iPhone:
Share > Add to Home Screen.

The checklist has no fixed herd limit for practical farm use (animal count field accepts 1–5000).
Records are stored in the browser's local storage on that device/browser. No cloud sync or account login.
